# 线性规划求解器实现总结

## 完成情况

### ✅ 核心功能
1. **单纯形法求解器** (`SimplexSolver`)
   - ✅ 支持最大化/最小化问题
   - ✅ 支持等式约束（=）

   - ✅ 支持打折类活动的条件逻辑线性化

## 关键修复

### 1. 单纯形法最大化问题处理
**问题**：最大化问题返回全零解

**原因**：`_isOptimal`和`_findPivotColumn`方法只考虑了最小化问题

**修复**：
- 修改`_isOptimal`方法，添加`isMaximize`参数
- 修改`_findPivotColumn`方法，添加`isMaximize`参数
- 对于最大化问题，反转判断逻辑

### 2. Big-M约束实现
**实现**：
- 创建`BigMConstraints`类
- 实现4个Big-M约束：
  1. 门槛约束：B_i >= T_i * z_i
  2. 上界：D_i <= (1-r_i) * A_i
  3. 下界：D_i >= (1-r_i) * A_i - (1-r_i) * M * (1-z_i)
  4. Gating：D_i <= (1-r_i) * M * z_i

## 使用示例

### 基本使用
```dart
import 'package:demo_flutter/linear_programming/linear_programming.dart';

// 创建线性规划问题
final problem = LinearProgram(
  optimizationType: OptimizationType.maximize,
  objectiveCoefficients: [3.0, 2.0],
  constraintMatrix: [
    [1.0, 1.0],
    [2.0, 1.0],
  ],
  constraintRhs: [4.0, 6.0],
  constraintTypes: [
    ConstraintType.lessThanOrEqual,
    ConstraintType.lessThanOrEqual,
  ],
);

// 求解
final result = SimplexSolver.solve(problem);
```

### 营销活动使用
```dart
import 'package:demo_flutter/marketing_campaign/marketing_ilp_builder.dart';

// 构建模型
final builder = MarketingILPBuilder(
  orders: orders,
  promotions: promotions,
  amountMatrix: amountMatrix,
  countMatrix: countMatrix,
);

// 求解
final problem = builder.build();
final result = IntegerSolver.solve(problem);
```

## 性能特点

- **小规模问题**（< 10个订单，< 10个活动）：求解时间 < 1秒
- **中等规模问题**（10-50个订单，10-20个活动）：求解时间 1-10秒
- **大规模问题**（> 50个订单，> 20个活动）：可能需要优化（分组、超时等）

## 已知限制

1. **求解器性能**：对于大规模问题，分支定界法可能较慢
2. **内存使用**：大规模问题的变量和约束矩阵可能占用较多内存
3. **数值精度**：使用浮点数，可能存在数值误差（epsilon = 1e-10）

## 后续优化建议

1. **活动分组优化**：根据文档中的优化方案，实现活动分组
2. **求解器参数调优**：添加超时、容差等参数
3. **启发式算法**：对于大规模问题，提供快速近似解
4. **并行求解**：利用多核CPU并行求解多个子问题
