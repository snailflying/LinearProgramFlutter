## 技术细节

### 变量布局
- `y_{o,i}`: 订单o是否参加活动i (索引: o * numValidPromotions + i)
- `A_i`: 活动i的总金额 (索引: numOrders * numValidPromotions + i)
- `C_i`: 活动i的总件数 (索引: numOrders * numValidPromotions + numValidPromotions + i)
- `D_i`: 活动i的优惠金额 (索引: numOrders * numValidPromotions + 2 * numValidPromotions + i)
- `t_i`: 活动i的触发次数 (索引: numOrders * numValidPromotions + 3 * numValidPromotions + i)

### 约束类型
1. **每个订单最多参加一个活动**: `sum_i y_{o,i} <= 1`
2. **聚合金额/件数**: `A_i = sum_o a_{o,i} * y_{o,i}`, `C_i = sum_o c_{o,i} * y_{o,i}`
3. **门槛约束**: `A_i >= T_i * t_i` (或 `C_i >= T_i * t_i`)
4. **优惠金额**: `D_i = L_i * t_i`

### 目标函数
最大化总优惠金额: `max sum_i D_i`
